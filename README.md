# Craig Huckerby

Independent AI researcher and full-stack developer.

I design and build autonomous systems, multi-agent architectures, and safety mechanisms  
**under real constraints: a Samsung Galaxy S23 and free-tier AI APIs only.**

---

### What I work on

- Self-modifying code systems with explicit stop conditions and verification layers
- Multi-agent debate and governance protocols
- Runtime safety controls (sanitisation, risk scoring, human approval gates)
- Lightweight agents and orchestration that can run without paid infrastructure

Everything is built and tested on mobile, using only free model access (Gemini, Grok, Cerebras, etc.).
